Nozzle angle
calibration test.

Set a nozzle tilt and bead-relative orientation, then generate a test matrix comparing flow percentages and layer heights. Each flow value becomes a row; each layer height becomes a column.

01 / DEFINE THE TEST

Test matrix parameters

SETUP
1 Nozzle tilt SINGLE TARGET / DEGREES

Positive and negative values tilt in opposite directions about the selected rotary axis. The orientation setting is preserved by automatically rotating the matrix 180° when the tilt sign is negative. At 0°, the nozzle is upright and orientation has no effect.

2 Nozzle & layer stack MM / LAYERS

Three-wall spacing uses the fixed nozzle-hole extrusion width and Slic3r flow math for nominal overlap.

3 Extrusion calibration FLOW / PERCENT
4 Layer height calibration MM / COLUMNS

Layer heights accept 0.01 mm increments. Minimum safe height uses physical nozzle-tip diameter; maximum is 1.5 × nozzle-hole diameter.

5 Nozzle orientation RELATIVE TO BEAD DIRECTION

Trailing edge tilts away from the deposited bead for simpler printing and fewer collisions. Leading edge tilts toward the bead for complex geometry and acute angles, but can affect print quality and mechanical performance. Adjacent tilts 90° to the bead for feature clearance. Hybrid options place the matrix halfway between the corresponding edge and adjacent orientations. The complete matrix rotates to align with the selected firmware rotary axis. Verify axis direction and orientation on your printer before printing.

6 Printer & bed MM UNLESS NOTED

Pattern is centered on the bed center. Leave center coordinates blank to calculate them from bed size and origin mode. Circular beds use bed size X as the diameter.

Common printer convention: A rotates about X, B about Y, and C about Z. Confirm the selected axis is enabled and measured in degrees by your firmware.

7 Retraction & Z-hop MM / MM/S
8 First layer & matrix base MM / MM/S

A single solid base layer under the matrix connects all labels and test lines. No individual skirts are printed.

9 Print settings MM/S / °C
10 Pressure advance PRE-CALIBRATED / OPTIONAL OVERRIDE

Pressure advance should be calibrated before this test. 0.04 is a starting default for direct drive. Firmware units differ; uncheck to retain the printer's configured value.

11 Start / end G-code OPTIONAL OVERRIDES

Custom blocks are emitted only when enabled. Tokens: [BED_TEMP], [HOTEND_TEMP], [TOOL_INDEX], [EXTRUDER_NAME]. Review all commands before printing.
