Tip clearance is part of the test.

The target layer height is checked against the lowest point of a tilted, circular nozzle rim before G-code can be generated.

OUTPUT FILE angle-calibration.gcode
FIELD NOTE01

One model. Explicit assumptions.

Enter one tilt angle from the surface normal (0° is vertical) and one target layer height. The nozzle outlet is modeled as a circular rim rotating about its centroid. Its vertical drop is r · sin(θ), equivalently √(r² − (r · cos(θ))²); the target height must meet or exceed that value. This checks exit-face clearance, not the full nozzle body or machine.

Bead volume approximation

Line width w is fixed to the nozzle tip diameter; bead area is A = (w − h)h + π(h/2)². Each specimen prints the requested number of layers at the target height, with one flow multiplier per specimen. Printed markers identify specimen, multiplier, and tilt (T); comments list all settings. Stacking builds up from the nominal first-layer height but does not model a separate first-layer compensation value.
